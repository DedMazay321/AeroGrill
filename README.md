# АэроГриль

Приложение для Android с рецептами для аэрогриля Weissgauff WAF 720 DB Steam Fry: пошаговые инструкции, подбор блюд и меню по КБЖУ, список покупок, таймер.

## Установка

Скачайте на телефон последнюю версию: **[AeroGrill.apk](https://github.com/DedMazay321/AeroGrill/releases/latest/download/AeroGrill.apk)**, откройте файл и разрешите установку.

Дальше приложение обновляется само: «Справка» → «Проверить обновления» → «Скачать и установить».

## Выпуск новой версии

```bash
tools/release.sh 1.2.0 "Что изменилось в этой версии"
```

Скрипт поднимает номер версии, дополняет [CHANGELOG.md](CHANGELOG.md), собирает APK, ставит тег `v1.2.0` и публикует релиз на GitHub.
Нужны JDK 17, Android SDK и файл ключа `signing/aerogrill.keystore` (в репозитории его нет — обновления должны быть подписаны тем же ключом).

Интерфейс лежит в `app/src/main/assets/www`, для просмотра в браузере: `node tools/serve.js`.
