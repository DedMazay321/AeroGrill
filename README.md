# АэроГриль

Приложение для Android с рецептами для аэрогриля Weissgauff WAF 720 DB Steam Fry: пошаговые инструкции, подбор блюд и меню по КБЖУ, список покупок, таймер.

## Установка

Скачайте на телефон последнюю версию: **[AeroGrill.apk](https://github.com/DedMazay321/AeroGrill/releases/latest/download/AeroGrill.apk)**, откройте файл и разрешите установку.

Дальше приложение обновляется само: при запуске оно скачивает из релиза архив со страницами и рецептами (`www-shellN.zip`) и включает его при следующем запуске — без переустановки. APK нужен заново, только если изменилась сама Android-оболочка.

## Выпуск новой версии

```bash
tools/release.sh 1.2.0 "Что изменилось в этой версии"
```

Скрипт поднимает номер версии, дополняет [CHANGELOG.md](CHANGELOG.md), собирает APK и архив страниц, ставит тег `v1.2.0` и публикует релиз на GitHub. Если с прошлого релиза менялся Java-код, манифест или ресурсы, он увеличивает номер оболочки (`SHELL` в `MainActivity.java`) — такое обновление телефоны ставят через APK.
Нужны JDK 17, Android SDK и файл ключа `signing/aerogrill.keystore` (в репозитории его нет — обновления должны быть подписаны тем же ключом).

Интерфейс лежит в `app/src/main/assets/www`, для просмотра в браузере: `node tools/serve.js`.

## Фотографии

Фото блюд взяты с Wikimedia Commons по свободным лицензиям (CC0, CC BY, CC BY-SA), обрезаны и уменьшены. Авторы и лицензии каждого снимка перечислены в `app/src/main/assets/www/js/data-photos.js` и в приложении: «Справка» → «Фотографии». Подбор фото: `python tools/photos.py`.
